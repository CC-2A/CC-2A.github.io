# Site professionnel CC-2A

Site officiel de **CC-2A – Plomberie Chauffage** à Ajaccio, publié sur <https://cc-2a.github.io/>.

## Contenu

- dépannage plomberie ;
- recherche et réparation de fuite avec essais et rapports ;
- remplacement de chauffe-eau ;
- chauffage hydraulique et radiateurs à eau ;
- débouchage ;
- réalisations ;
- offre pour syndics, agences et bailleurs.

Le site utilise des URL canoniques à la racine, un sitemap XML, des données structurées Schema.org et des redirections immédiates depuis l’ancienne arborescence `/cc2a-ajaccio/`.
